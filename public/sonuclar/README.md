# Sonuç görselleri

Öncesi–sonrası görselleri ve danışan hikayesi görselleri buraya konur.
Ayrıntılı yönerge: depo kökündeki `GORSELLER.md`.

**Kural:** görsel yayınlamak için imzalı hasta onam formu şarttır ve
uygulamayı yapan merkezin adı (`kaynak`) zorunludur. Kaynak yazılmayan
kayıt sitede görünmez.

Adlandırma: `vaka-1-oncesi.webp`, `vaka-1-sonrasi.webp`
Ölçü: kare (1:1), en az 800×800px, aynı açı ve ışık.
